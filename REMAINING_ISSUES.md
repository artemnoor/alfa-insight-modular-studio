# Оставшиеся ограничения

1. **BLOCKED — данные пользовательского продукта.** Чистый клон содержит только `data/.gitkeep`; отсутствуют `df_Uid_data_hack.csv`, `news_pipeline.sqlite` и `stage2_kb.json`. Поэтому `/` загружается, но список компаний пуст. Данные специально не копировались и не коммитились.
2. **PARTIAL — News Intelligence.** Изолированная fixture проверяет реальные T08 taxonomy choice и T09 local embedding алгоритмы. Полный T08 classification требует разрешённую модель/ключ и отдельного явного запуска; внешний AI в модульной среде закрыт.
3. **PARTIAL — Bank Research.** BM25 работает на prepared chunks. Каталог банковских PDF, индекс, document-level citations и ошибки OCR не представлены в рабочей копии.
4. **PARTIAL — Impact Analysis.** Модуль проверяет реальные evidence guards, но самостоятельно не запускает модельный генератор анализа; это требует явного пути из клиентского API либо отдельной локальной фикстуры генерации.
5. **PARTIAL — Evidence Verification.** Точная цитата и source ID проверяются существующей функцией. Смысловую применимость и числовые противоречия модуль отдельно не оценивает.
6. **PARTIAL — AI Agent persistence и режимы.** Инструменты и план реально исполняются orchestrator на synthetic input, но ответы модели fixture, история существует в рамках UI-сессии/временной БД, сравнение запусков ограничено. Approved External AI selector намеренно не включён.
7. **PARTIAL — физическое перемещение ядра.** Для совместимости алгоритмы остались на существующих канонических путях. Модульные backend adapters дают изолированные entrypoints, но физический перенос файлов с долгоживущими импортами — отдельный безопасный этап.
8. **Не проверено — несколько независимых Vite-процессов.** `studio:module` открывает прямую страницу в общем портале и поднимает только один API + Vite, а не отдельную копию React. Отдельная параллельная портовая сессия каждого модуля не нужна для fixture тестов.

Внешние AI вызовы, массовые задачи, изменение CSV/SQLite и публикация клиентских данных не выполнялись. T09/T10 Postgres integration tests не запускались без настроенной базы.
