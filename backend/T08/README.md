# T08: классификация новостей

Локальный модуль для классификации новостных текстов и извлечения сущностей. Требуется Node.js 22+.

## Запуск и тесты

~~~powershell
npm start
npm run test:taxonomy
npm run test:semantic-evidence
npm run test:explicit-entities
~~~

Модуль не содержит банковских клиентских данных. Секреты задаются только через локальные переменные окружения; не добавляйте их в Git.
