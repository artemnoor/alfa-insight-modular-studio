# T10: понимание бизнеса

Модуль профиля компании, бизнес-связей и поиска доказательств. Требуется Node.js 22+.

~~~powershell
npm start
npm test
~~~

Нужна отдельная локальная PostgreSQL-база, если вы проверяете интеграцию. Внешние модели и сетевые источники используйте только с разрешёнными данными и настройками. Не добавляйте клиентские данные или секреты в Git.
