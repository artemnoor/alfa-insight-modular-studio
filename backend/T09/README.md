# T09: дедупликация и векторизация

Локальный сервис объединения похожих публикаций. Требуется Node.js 22+.

~~~powershell
npm start
npm test
~~~

Интеграционные PostgreSQL-тесты запускаются отдельно только на намеренно созданной локальной тестовой базе. Настройки соединения задаются в локальном .env, который не коммитится.
