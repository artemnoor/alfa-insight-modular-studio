# Локальный конвейер данных

Сервис разработки для локальных компонентов обработки публикаций. Требуются Node.js 22+ и, для базы, Docker Compose.

~~~powershell
npm start
npm test
~~~

Перед запуском базы проверьте compose.yaml и замените локальные пароли на собственные. Не помещайте секреты и рабочие данные в Git.
