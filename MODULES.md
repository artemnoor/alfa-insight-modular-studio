# Модули Alfa Insight

| № | Модуль | Папка | API | Frontend | Тесты | Команда | Статус |
|---:|---|---|---|---|---|---|---|
| 01 | News Collector | `modules/01-news-collector` | `/api/modules/news-collector/*` | `frontend/ModulePage.tsx` | `tests/test_module.py`, 3 RSS сценария | `npm run test:module -- news-collector` | PASS: parser/dedup/date/errors на temporary SQLite; CBR RSS вручную получена живым запросом и сохранена только в clone-local SQLite |
| 02 | News Intelligence | `modules/02-news-intelligence` | `/api/modules/news-intelligence/*` | `frontend/ModulePage.tsx` | `tests/test_module.py`, 4 сценария | `npm run test:module -- news-intelligence` | Fixture tests remain network-isolated; Local Data runs T09 vectors against the processed archive; External AI manually runs production T08/T09 with approved Polza models and a 0.05–5 ₽ per-run cap |
| 03 | Business Intelligence | `modules/03-business-intelligence` | `/api/modules/business-intelligence/*` | `frontend/ModulePage.tsx` | `tests/test_module.py`, synthetic CSV and Local Data | `npm run test:module -- business-intelligence` | Real CSV profile, graph and payment aggregates; optional one-call Polza interpretation does not alter source results |
| 04 | Personalization | `modules/04-personalization` | `/api/modules/personalization/*` | `frontend/ModulePage.tsx` | `tests/test_module.py`, 3 scenarios | `npm run test:module -- personalization` | Real deterministic ranking; optional Polza explanations cannot change scores or order; no independent gold labels for ranking metrics |
| 05 | Impact Analysis | `modules/05-impact-analysis` | `/api/modules/impact-analysis/*` | `frontend/ModulePage.tsx` | `tests/test_module.py`, 3 scenarios | `npm run test:module -- impact-analysis` | Local mode loads the chosen real profile and event; External AI calls the existing generator and applies evidence guards |
| 06 | Bank Research / RAG | `modules/06-bank-research` | `/api/modules/bank-research/*` | `frontend/ModulePage.tsx` | `tests/test_module.py`, synthetic pages and Local Data | `npm run test:module -- bank-research` | Real BM25 retrieval from local bank index; optional Polza interpretation sees up to five retrieved fragments; relevance remains a separate judgement |
| 07 | AI Agent Studio | `modules/07-ai-agent` | `/api/modules/ai-agent/*` | `frontend/ModulePage.tsx` | `tests/test_module.py`, 4 scenarios | `npm run test:module -- ai-agent` | Fixture run is free; External AI now uses selected local company/event and persistent agent history, with explicit per-run cap; no paid run is automatic |
| 08 | Evidence Verification | `modules/08-evidence-verification` | `/api/modules/evidence-verification/*` | `frontend/ModulePage.tsx` | `tests/test_module.py`, 3 сценария | `npm run test:module -- evidence-verification` | Exact quote matching stays local; optional Polza semantic review is shown separately and explicitly is not independent verification |
| 09 | Alfa Insight Product | `modules/09-alfa-product` | `/api/modules/alfa-product/*` | `frontend/ModulePage.tsx`, продукт `/` | `tests/test_module.py`, 3 contract scenarios | `npm run test:module -- alfa-product` | Studio points to the real product and checks connected local profile/archive; product chat and deep research use the existing manual AI actions when opted in |

Каждая папка содержит `backend/`, `frontend/`, `tests/`, `fixtures/`, `README.md`. У модуля 02 есть локальный Node runner, у остальных backend entrypoint — `adapter.py`. Общий каркас UI находится в `shared/frontend/ModuleWorkbench.tsx`; разные поля и представления результата описаны в собственном `frontend/ModulePage.tsx` каждого модуля.
