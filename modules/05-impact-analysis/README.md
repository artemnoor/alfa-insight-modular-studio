# 05-impact-analysis

Isolated workspace for **impact-analysis**. Open `/studio/impact-analysis`; fixture scenarios run with `npm run test:module -- impact-analysis`. `Local Data` selects a real company and processed news event. `External AI` manually runs the existing impact-analysis pipeline and evidence guards on those inputs using Polza; the selected profile and event are sent to the provider. A run is never started just by opening the page.
