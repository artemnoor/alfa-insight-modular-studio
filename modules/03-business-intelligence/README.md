# 03-business-intelligence

Изолированное рабочее пространство Business Intelligence. Маршрут: `/studio/business-intelligence`; сценарии: `npm run test:module -- business-intelligence`. По умолчанию используется Local Data, если CSV подключены, иначе бесплатные `Fixture`; внешний AI не выбирается автоматически. `Fixture` строит граф на временных CSV/SQLite. `Local Data` читает профили, person links и payment CSV из `ALFA_INSIGHT_DATA_ROOT`; производный `business_network.sqlite` создаётся локально. В `External AI` Polza получает ограниченные поля профиля, агрегаты платежей и число связей для текстовой интерпретации; граф и показатели рассчитываются локально. При ошибке AI локальный результат сохраняется со статусом `PARTIAL`, а подтверждённые расходы показываются отдельно от неизвестной стоимости. Исходные CSV не меняются. Платёжный поток не доказывает поставку, а общий GROUP_ID — корпоративный контроль.
