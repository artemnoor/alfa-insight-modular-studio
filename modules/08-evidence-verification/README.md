# 08-evidence-verification

Isolated workspace for **evidence-verification**. Open `/studio/evidence-verification`; fixture scenarios run with `npm run test:module -- evidence-verification`. The canonical exact-quote/source check is `backend/evidence_core.py`; Impact Analysis imports the same function, so there is one implementation. `Local Data` checks exact quote presence. `External AI` additionally sends the manually supplied claims, quotes, and source excerpts to Polza for semantic review. That review is not independent expert verification. Provider calls require explicit opt-in and a manual run.
