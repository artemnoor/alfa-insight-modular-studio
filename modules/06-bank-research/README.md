# 06-bank-research

Изолированное рабочее пространство Bank Research. Маршрут: `/studio/bank-research`; сценарии: `npm run test:module -- bank-research`. `Fixture` использует подготовленные страницы, `Local Data` выполняет поиск по локальной базе знаний. `External AI` вручную передаёт Polza найденные локальным поиском фрагменты для интерпретации; сам поиск остаётся локальным. BM25-совпадение не подтверждает позицию Альфа-Банка или применимость к событию.
