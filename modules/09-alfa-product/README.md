# 09-alfa-product

**Alfa Insight Product** owns the end-user React client at `frontend/product/` and its existing Python API at `backend/react_api.py`. The API retains legacy route wrappers for the existing product and Streamlit workflows. Open `/studio/alfa-product` for its developer integration view and `/` or `/product` for the customer experience. Existing chat and research routes can use the configured approved Polza model after `ALFA_ALLOW_EXTERNAL_AI=true`; the end-user action must be explicitly submitted. Studio `Local Data` confirms the real company/news inputs without starting a provider call. Fixture contract scenarios remain synthetic.
