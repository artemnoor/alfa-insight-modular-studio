# 09-alfa-product

**Alfa Insight Product** owns the end-user React client at `frontend/product/` and its existing Python API at `backend/react_api.py`. The API retains legacy route wrappers for the existing product and Streamlit workflows. Open `/studio/alfa-product` for its developer integration view and `/` or `/product` for the customer experience. Run `npm run test:module -- alfa-product` for its unit and prepared contract scenarios. Fixture tests are synthetic; external AI is disabled.
