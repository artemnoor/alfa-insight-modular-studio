# T08 datasets

Downloaded on 2026-10-15. Original sources are retained where available; IPTC copies are also provided as normalized JSON for application-side use.

## IPTC Media Topics

- iptc-media-topics-en-US.xlsx — official IPTC workbook, last updated 2026-07-09.
- iptc-media-topics-en-US.json — JSON export of the workbook, including IDs, hierarchy, labels, definitions, retirement dates, and mappings.
- Source tree view: https://www.iptc.org/std/NewsCodes/treeview/mediatopic/mediatopic-en-US.html
- Download: https://www.iptc.org/std/NewsCodes/IPTC-MediaTopic-NewsCodes.xlsx
- License: CC BY 4.0. Attribution: IPTC, International Press Telecommunications Council.

## Full SENTiVENT dataset

- sentivent/ — complete Hugging Face dataset snapshot (141 files, including data splits, metadata, README, and license files).
- Source: https://huggingface.co/datasets/GillesJacobs/sentivent
- The dataset card declares CC BY 4.0. The repository also includes supplemental license notices for integration adapters; see sentivent/LICENSE, sentivent/LICENSES/NOTICE.md, and related files.
- The typology JSON above is a separate source file and is not part of the Hugging Face snapshot.
